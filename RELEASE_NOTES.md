## Что нового в VERSION

- **Подписи к графикам и картинкам** со своим текстом и **автонумерацией** («Рисунок 1 — …»): номера по порядку чтения, сквозные по страницам, настраиваемый префикс; в Word номер — настоящее поле `SEQ` (обновление номеров, список иллюстраций). «Подписать все» / «Убрать подписи» для блока.
- **Значения переменных дашборда из Grafana:** выпадающие списки подгружаются по запросу (Prometheus `label_values(...)`, зависимые переменные `$job → nodename`, custom-переменные); для неподдерживаемых датасорсов — понятное сообщение и ручной ввод.
- **Дашборды со свёрнутыми строками** раскладываются без наложений: строки раскрываются, панели ниже сдвигаются.
- Компактные плашки значений переменных на графиках в редакторе.

## Запуск

```
java -jar grafana-reporter-VERSION.jar    # http://localhost:8080
```
Для картинок графиков в Grafana нужен `grafana-image-renderer`; токен service account вводится в интерфейсе или через `GRAFANA_URL` / `GRAFANA_TOKEN`.
