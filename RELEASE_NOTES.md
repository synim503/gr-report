## Что нового в VERSION

- **Переменные дашборда сразу в интерфейсе:** при раскрытии дашборда, в инспекторе графика и блока и в диалоге вставки — с выпадающим списком значений из Grafana; плашка с активными значениями на графике в редакторе.
- **Целый дашборд как блок без «каши»:** блок вставляется в ширину страницы, а дашборд выше страницы раскладывается на несколько страниц с сохранением сетки (лимит блока — 300 графиков).
- **Параллельность генерации** в настройках (1–16, по умолчанию 4): сколько графиков одного отчёта Grafana рендерит одновременно.
- **Задачи сборки:** отчёты собираются в фоне; панель «Задачи» с прогрессом, **отменой** (прерывает идущие запросы к Grafana), повторной загрузкой и очисткой. Новые API: `/api/reports/jobs`.

## Запуск

```
java -jar grafana-reporter-VERSION.jar    # http://localhost:8080
```
Для картинок графиков в Grafana нужен `grafana-image-renderer`; токен service account вводится в интерфейсе или через `GRAFANA_URL` / `GRAFANA_TOKEN`.
