# Grafana Reporter

Визуальный редактор макета страницы Word + генератор отчётов из Grafana.
Бэкенд — Java 17 / Spring Boot, фронтенд — React (Vite, TipTap).

## Как это работает
1. В редакторе вы перетаскиваете на страницу A4/A3/A5/Letter **графики Grafana**, **текст** и **изображения**.
   Есть привязка к краям/центру/полям/соседним блокам (с направляющими), выравнивание, распределение, слои, undo/redo, несколько страниц.
2. Текст форматируется как в Word: шрифт, размер, цвет, выделение, **B/I/U/S**, индексы, заголовки, выравнивание (в т.ч. по ширине),
   маркированные и нумерованные списки, цитаты, ссылки, межстрочный интервал, переменные `{{date}}`, `{{from}}`, `{{to}}`, `{{name}}` и свои.
3. **Блоки**: набор графиков одного дашборда с готовой раскладкой (например «Утилизация Linux»). Можно вставить дашборд целиком
   («▦ Весь дашборд как блок») или выделить несколько графиков → «Сохранить как блок». У блока есть **переменные** (host, job, …) —
   значения уходят в Grafana как `var-host=…` для каждого графика блока. Значение может быть ссылкой `{{server}}` на **переменную отчёта**.
4. Переменные дашборда (host, job…) показываются сразу: в боковой панели при раскрытии дашборда, в инспекторе графика/блока (выпадающий список значений из Grafana
   или свой текст / `{{переменная отчёта}}`) и плашкой на самом графике в редакторе (в документ плашка не попадает).
5. Дашборд целиком вставляется блоком в ширину страницы; если он выше страницы — раскладывается на несколько страниц с сохранением сетки.
6. «⬇ Сформировать Word» → задача сборки в фоне (панель «Задачи» в верхней панели: прогресс по графикам, **отмена**, повторная загрузка, очистка).
   По готовности файл скачивается автоматически. Бэкенд запрашивает у Grafana картинки панелей (`/render/d-solo`, по токену) и собирает `.docx`:
   текст — абсолютно позиционированные рамки Word, графики — плавающие картинки, привязанные к странице. Верстка в Word = верстка в редакторе.

## Запуск
```bash
scripts/build.sh                                   # UI + jar
GRAFANA_URL=https://grafana.example.com GRAFANA_TOKEN=glsa_xxx \
  java -jar backend/target/grafana-reporter-1.0.0.jar   # http://localhost:8080
```
**Параллельность генерации** (сколько графиков одного отчёта Grafana рендерит одновременно, 1–16, по умолчанию 4) задаётся в настройках ⚙. Чем больше — тем быстрее отчёт, но выше нагрузка на Grafana/renderer.

URL и токен можно задать прямо в интерфейсе: при первом запуске на холсте появится карточка «Подключите Grafana» (токен проверяется перед сохранением, поле с кнопкой показать/скрыть),
позже — через плашку подключения в верхней панели или ⚙ в боковой панели (там же можно заменить или удалить токен). Есть светлая и тёмная тема. Данные (настройки, отчёты, блоки) — в `DATA_DIR` (по умолчанию `./data`).
Разработка: `cd backend && mvn spring-boot:run`, `cd frontend && npm run dev` (порт 5173, прокси на :8080).

### Требования к Grafana
* Токен service account с ролью **Viewer** (передаётся как `Authorization: Bearer`).
* Установленный **grafana-image-renderer** (картинки панелей рендерятся через `/render/d-solo/...`). Без него UI/генерация сообщат об этом явно.

## API
| | |
|---|---|
| `GET/PUT /api/settings`, `POST /api/grafana/test` | подключение и параллельность (токен наружу не отдаётся) |
| `GET /api/grafana/dashboards[?query=]`, `/dashboards/{uid}`, `/dashboards/{uid}/block`, `/panel-image` | обзор Grafana, автоблок из сетки дашборда |
| `CRUD /api/templates`, `CRUD /api/blocks` | отчёты и библиотека блоков |
| `POST /api/reports/generate[?strict=true&var-NAME=…]` | синхронно: тело — макет, ответ — `.docx` (+ `X-Report-Warnings`) |
| `POST /api/reports/jobs`, `GET /api/reports/jobs[/{id}[/file]]`, `DELETE /api/reports/jobs/{id}` | асинхронные задачи: запуск (202), список/статус с прогрессом, скачивание, отмена (running) / удаление (finished) |
| `POST /api/templates/{id}/generate` | то же для сохранённого отчёта (годится для cron) |

Сломавшийся график по умолчанию заменяется картинкой-заглушкой + предупреждение; с `strict=true` генерация падает.

## Тесты
`scripts/test-all.sh` — JUnit (клиент Grafana, генератор docx, REST), Vitest (геометрия/привязка/блоки), Playwright (весь UI против реального бэкенда и поддельного Grafana).

## Ограничения
* Таблицы внутри текстовых блоков не поддерживаются; Grafana-переменные с несколькими значениями передаются одной строкой.
* Приложение не имеет собственной аутентификации — держите его во внутренней сети / за reverse proxy. Токен Grafana хранится в `DATA_DIR/settings.json` (права 600).
* Порядок слоёв «текст под графиком» в LibreOffice может отображаться иначе, чем в Word (рамки текста рисуются поверх).
